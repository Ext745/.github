# Ext745/.github

Shared policy and community files for all [Ext745](https://github.com/Ext745) repositories.

GitHub automatically uses the community-health files here (`CONTRIBUTING.md`, `SECURITY.md`, `SUPPORT.md`, issue and PR templates) for any repo that doesn't have its own. Keeping one copy means they never drift between repos.

| File | Purpose |
|---|---|
| [APPROACH.md](APPROACH.md) | How my projects are built: AI-led, human-directed, real-hardware tested |
| [AI_POLICY.md](AI_POLICY.md) | AI usage, contribution rules, conduct in other projects |
| [CONTRIBUTING.md](CONTRIBUTING.md) | How to contribute |
| [SECURITY.md](SECURITY.md) | Reporting vulnerabilities privately |
| [SUPPORT.md](SUPPORT.md) | What to expect |
| `.github/ISSUE_TEMPLATE/`, `.github/pull_request_template.md` | Default templates, with AI disclosure and hardware-testing fields |

This repo must stay **public** for the defaults to apply.
