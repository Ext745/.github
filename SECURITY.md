# Security Policy

## Reporting a vulnerability
Please **don't open a public issue** for security problems.

Use GitHub's private reporting: go to the repository's **Security** tab and choose **Report a vulnerability**. If that option isn't available on a repo, open an issue that says only "security contact requested", with no details, and I'll set up a private channel.

Please include:
- the affected repository and commit or release
- what the issue is and its impact
- steps to reproduce, which **you've verified yourself** (unverified AI-generated reports will be closed)
- hardware and configuration, if relevant

## What to expect
This is best-effort, personal maintenance (see [SUPPORT.md](SUPPORT.md)). I'll acknowledge valid reports as soon as I can and credit reporters in the fix unless you'd prefer not to be named.

## Scope
Particularly relevant: network-facing projects (VPN/WireGuard clients, routers, web servers), firmware, and anything handling credentials or cellular modems. Hardware safety issues (e.g. a dangerous circuit value) are also welcome through the same channel.
